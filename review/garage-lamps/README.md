# Garage lamps review

This is a component review, not a deployable wall or accepted phone experience. Serve this repository over localhost, for example `python -m http.server 8000` from the repository root, then open either:

- `review/garage-lamps/continuation-14/left-lamp-materials/assembly-browser.html`
- `review/garage-lamps/continuation-13/lamp-materials/assembly-browser.html`

Each page loads source-assigned bulb, glass, plastic, Emission and silver components for 16 lamps, with artifact hash and runtime contracts. Solid-glass refraction, source global illumination, actual shadows, complete walls, phones and physical-print alignment remain open. Both copied pages passed hardware-browser checks on RTX 5060 Ti; see proof/RESULT.json for the scope, diagnostics and hashes. Models are derivative review assets. A-Frame is copied from this repository's existing runtime; Three.js license and HDR provenance are retained alongside the runtime.
